In the input form, we copy and paste the sequence in the appropriate text area and we choose 'FASTA' in the format frame.

By clicking on the Check button, we obtain several information about the sequence:

  1. the length of the sequence (332) (which is displayed above the text area of the sequence),
  2. the smallest embedment size that can be used by the program (512) (which is displayed below),
  3. the detailled count of each amino acid in the sequence (which is displayed in the frame 'Statistics').

In the statistics frame, we can see that Alanine is the more frequent residue (96) followed by Serine (54), Glycine (46) and Proline (45). If statistics are given in percentage, we have respecively 28.9% of Alanine, 16,2% of Serine, 13.8% of Glycine and 13.5% of Proline.

We choose to analyse the peridocity of the more frequent residue, then we enter a weight of 1 for Analine in the frame Selection of residues , we set the cutoff to 0 to have a continuous graph and we choose a range of periodicities between 2 (min period) and 50 (max period).

By clicking on 'Submit', we obtain a result page composed of three parts: the summary of the query date, the result presented in a table and a graph (only if 'HTML page' is selected in the input form) displaying the relation between periodicity and intensity.

On the graphical representation below, we can see that biggest intensities are located between periods of 2 and 7.

Note that we can obtains a graph with smoother lines by selecting a bigger 'embedment size'. Follow this link to see the same graph with an embedment size of 4096.

To have more details, we can return to the 'Input form' by clicking the Back button of the browser and set the maximum periodicity to 7. Now, we can see on the new graph that the biggest intensities correspond to periodicities less than 3

We can again choose a smaller range of periodicities on the Input form. Below is the result for periodicities between 2 and 3:

We can exclude periodicities with small intensities by specifying a cutoff (minimum intensity displayed) bigger than 0 and get a bar graph containing periodicities with intensity greater or equal to the cutoff. Below is the same graph displayed by using a cutoff of 2.5.

We can also examine only a part of the sequence by changing the default values of Start residue and End residue. In the example sequence, we can see that there is a repetition of the pattern 'SYSAPAP' between residues 162 and 242. If we choose these values for the Start and the End residues, then we can see, in the graph below, that we obtain a big intensity for a periodicity of 2.26.

There is also a possibility to select more than one residue at the same time. For example, by selecting 'A' and 'Y' both with a weight of 1, we obtain the following graph:

We can see that now, the maximum intensity is bigger which is logical for this part of the CCC4 sequence where we have a repetition of the 'SYSAPAP' patern. The periodicity corresponding to the maximum intensity is, as expected, approximately two. Each two residues, we have a 'A' or a 'Y'. This is a special case and not a rule. Sometimes, selecting more than one residues may decrease the maximum intensity found or may give completly different results. For example, if we replace 'Y' by 'P', we calculate a maximum intensity of 2.54 for the same periodicity. But, if we change the range (by specifying 50 as the maximum period), we see that this is not the maximum intensity which is now of 13.53 for a periodicity of 8.98.
