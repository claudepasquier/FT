# Authors and contributors

## Original program and method (FT)

The FT program was published as: Pasquier C.M., Promponas V.I.,
Varvayannis N.J. & Hamodrakas S.J. (1998), *A web server to locate
periodicities in a sequence*, Bioinformatics 14(8), 749–750
([doi:10.1093/oxfordjournals.bioinformatics.a011054](https://doi.org/10.1093/oxfordjournals.bioinformatics.a011054)).

It was developed at the **Division of Cell Biology and Biophysics, Department
of Biology, University of Athens, Greece**.

- **Claude Pasquier** — **main author of the code**; original C implementation
- **Nikos J. Varvayannis** — co-developer of the program
- **Vasilis I. Promponas** — co-developer of the program
- **Stavros J. Hamodrakas** — co-author; author of the original 1985 Fortran
  program on which the FFT core is based (Hamodrakas et al., 1985)

The core algorithm derives from work of **Dr. A.D. McLachlan** (embedding of
the residue array into a zero-padded array for higher resolution;
McLachlan, 1977).
