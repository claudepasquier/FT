1. About the Program

This computer program uses a Fast Fourier Transform (FFT) algorithm to locate residue periodicities in either aminoacid or DNA sequences.

The project consists of two basic parts. The main part of the program is based on an algorithm of Dr. A.D. McLachlan and it is a conversion in C++ of a Fortran program written by Dr. S.J. Hamodrakas in 1985 (Hamodrakas et.al., 1985) . Each sequence of N residues is represented as a linear array of N terms, with each term given a value of 1 or 0 according to whether the condition considered (i.e. presence of a G residue) is or is not satisfied. To increase resolution, this array is embedded in a larger array of zeroes (McLachlan, 1977). The transformation is performed by using an FFT algorithm.

The part of data-input is written in Java. After providing information about the sequence and the residue(s) he is interested in, the user execute the calculation on a computer of the University of Athens. The results are displayed either in an HTML page, in text mode. On the HTML page, the relations between intensities and periods are also represented as a graph.
