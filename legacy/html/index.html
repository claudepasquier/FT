Identification of Residue Periodicities in Sequences


Varvayannis, N.J., Pasquier, C.M., Promponas, V.I. and Hamodrakas, S.J.
Division of Cell Biology and Biophysics,
Department of Biology,
University of Athens
Greece

This program can locate residue periodicities in either aminoacid or DNA sequences. It is based on an algorithm of Dr. A.D. McLachlan (1977).

NOTE: You must use a Java compatible browser to run the application.
To have better results, we suggest you to use Netscape 3.0 or better. You can download the latest version of the navigator by clicking on the icon.
