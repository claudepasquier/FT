How to copy/Paste a sequence


There is several way to copy and paste a text from an application to another one, depending on the system used :

  • on a PC running Windows 95/NT
    In the window of an application displaying the sequence, select the content of the sequence with the mouse, use the Copy command in the 'Edit' menu of the application, the Copy command displayed when you click the right mouse button or the shortcut Ctrl-C. Place the cursor in the text area of the Input form and use the Paste command displayed when the right mouse button is clicked or the shortcut Ctrl-V.
  • On a SGI workstation
    In the window of an application displaying the sequence, select the content of the sequence with the mouse. Place the cursor in the text area of the Input form and click on the middle mouse button.
  • On a SUN workstation
    In the window of an application displaying the sequence, select the content of the sequence with the mouse, use the Copy command in the 'Edit' menu of the application or the shortcut Ctrl-C. Place the cursor in the text area of the Input form and use the shortcut Ctrl-V or click the middle mouse button.
